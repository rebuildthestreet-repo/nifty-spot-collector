# nifty-spot-intraday-collector dependencies -- fully pinned.
#
# Verified working as of August 2026. Two different provenances, so read the
# right justification when you bump one:
#
#   upstox-python-sdk and its transitive deps (urllib3, certifi,
#   python-dateutil, six) are pinned to the EXACT versions running in the
#   source system's venv on
#   2026-08-09, because src/upstox/adapter.py and src/upstox/session.py call
#   version-specific generated SDK method names (HistoryV3Api,
#   get_historical_candle_data1 -- note the trailing "1"). An unpinned
#   install of a later SDK release can rename them; the failure is an
#   AttributeError at call time, not an install-time error.
#
#   matplotlib and its transitive deps are NOT inherited from anywhere --
#   there is no Python chart renderer in the source to inherit a pin from
#   (see src/render/chart.py's docstring). This pin is simply "the latest
#   matplotlib release as of 2026-08-09, resolved in a scratch venv". It has
#   no history to defend and is the one pin here you should feel free to
#   bump first.
#
# tzdata is required, not optional, despite this being a "standard library"
# zoneinfo use: ZoneInfo("Asia/Kolkata") raises ZoneInfoNotFoundError at
# IMPORT time on any slim base image (python:3.12-slim, alpine, distroless)
# that lacks the OS tzdata package. Python's zoneinfo falls back to this PyPI
# package when the OS one is missing, which is exactly the situation inside
# Docker (see Dockerfile).
#
# To bump a pin: install the new version in a scratch venv, run the test
# suite against it, and only then update this file -- one dependency, one
# change, per the same discipline services/analytics/requirements.txt uses
# in the source repo.
